# Agents

## Overview

Multi-agent system configuration for Solana Hackathon project.

## Available Agents

| Agent | Model | Role |
|-------|-------|------|
| opencode | big-pickle | Code generation, refactoring, debugging |
| gemini | Gemini 3.1 | Analysis, research, documentation |
| opus | Opus | Architecture, complex reasoning, review |

## Usage

Agents are invoked via task delegation or direct configuration.
